# 公开分支说明

`V1_7` 保存 v1.7 的完整运行模块、独立测试、合成样本、说明及可复现构建脚本。

本分支把生产绑定移到 Google Apps Script 的脚本属性中。它与已部署的内部版本使用相同的业务流程，但构建文件的字节和校验值不同，不应作为内部部署包的逐字节备份。

## 纳入仓库

- `nj_load_sync/`：运行源码、测试及合成测试数据。
- `scripts/build_v1_7.py`：按固定清单构建，不读取工作区临时数据或生产备份。
- `dist/WTC_LoadSync.gs`：由上述源码生成的完整脚本。
- `dist/release-manifest.json`：版本、测试数量及源码校验值。
- `README.md`、`docs/`：操作说明、配置要求和发布边界。

## 排除内容

不纳入 API Key、OAuth token、真实账号资料、生产表格绑定、实际库存、照片回单、业务样本、线上日志、升级前备份及内部 ZIP/RAR 安装包。

`.gitignore` 只防止后续误加入未跟踪文件，不能清理已有提交历史。新分支继承的历史仍可查看；删除分支当前目录中的内部压缩包不代表它已从主分支或历史记录消失。

## 发布与上线分开

提交 GitHub 分支不会修改正在运行的 Google Apps Script，也不会修改仓库业务表。线上升级需要由安装账号另行执行配置、升级与验收。

本分支没有指定开源许可证。公开可见不代表已授予任意使用、再分发或商用授权；许可证应由项目权利人另行确定。
